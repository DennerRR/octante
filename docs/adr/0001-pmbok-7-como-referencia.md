# PMBOK 7 continua como referência, mesmo com o PMBOK 8 publicado

O Octante segue o PMBOK® Guide 7ª edição (12 princípios, 8 domínios de desempenho), embora o PMI tenha publicado a 8ª edição em 2025. Ficamos no 7 porque o protótipo inteiro foi construído sobre ele e porque o PMO ainda não tem acesso ao texto do PMBOK 8, então não há como adaptar com fidelidade. A intenção é migrar para o PMBOK 8 no futuro, como uma decisão própria, que substituirá este ADR.
